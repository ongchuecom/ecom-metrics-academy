GPM: Doanh thu trên mỗi 1.000 lượt xem Live/Video (GPM)

Mỗi 1.000 lượt xem ra bao nhiêu tiền

GPM là doanh thu tạo ra trên mỗi 1.000 lượt xem phiên Live hoặc video. Ví dụ: phiên Live 20.000 lượt xem, ra 30tr GMV (tổng giá trị đơn đặt). GPM = 30tr ÷ 20.000 × 1.000 = 1,5tr.

Phiên đông người xem chưa chắc ra tiền. GPM bỏ qua chuyện to hay nhỏ, chỉ hỏi: mỗi 1.000 người xem ra bao nhiêu tiền. Nhờ vậy mới so được host với host, phiên với phiên, video với video.

Công thức

GPM = (Tổng doanh thu tạo ra / Tổng lượt xem phiên Live hoặc video) × 1.000

Dùng GPM để so host thế nào?

Host A kéo được nhiều người xem hơn gần 3 lần, GMV cao hơn. Nhưng mỗi 1.000 lượt xem, host B ra 2,2tr, host A chỉ 1tr. Host B bán giỏi hơn, host A giỏi giữ chân người xem.

Vậy nên đưa host B vào khung giờ đông người, còn host A thì tập lại phần chốt. Lượt xem có thể mua bằng Ads mồi, nhưng GPM thấp thì Ads mồi càng nhiều càng lỗ.

Hay hiểu sai

  • So GPM giữa hai sản phẩm giá chênh nhau quá xa, rồi kết luận host này giỏi hơn host kia.
  • Tính GPM bằng GMV gồm cả đơn sau này huỷ, hoàn.
  • Chỉ nhìn lượt xem phiên Live mà không chia ra tiền.

Nhớ một câu: Đông người xem chưa chắc ra tiền. So host, so phiên bằng GPM.
